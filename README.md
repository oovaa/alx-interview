## 🎯 Overview

Algorithm and data structure challenges from the **ALX Interview Preparation** curriculum. Each project solves a classic interview problem with optimal time/space complexity.

---

## 📁 Projects (11 Challenges)

| Project | Problem | Complexity | Key Concepts |
|---------|---------|------------|--------------|
| [`0x00-pascal_triangle`](0x00-pascal_triangle) | Generate Pascal's Triangle | O(n²) | Dynamic programming, combinatorics |
| [`0x01-lockboxes`](0x01-lockboxes) | Lockboxes (key/lock graph) | O(n) | Graph traversal, DFS/BFS |
| [`0x02-minimum_operations`](0x02-minimum_operations) | Min operations to reach n | O(√n) | Prime factorization, greedy |
| [`0x03-log_parsing`](0x03-log_parsing) | Parse HTTP logs in real-time | O(n) | Streaming, regex, counters |
| [`0x04-utf8_validation`](0x04-utf8_validation) | Validate UTF-8 encoding | O(n) | Bitwise operations, Unicode |
| [`0x05-nqueens`](0x05-nqueens) | N-Queens problem | O(n!) | Backtracking, recursion |
| [`0x06-starwars_api`](0x06-starwars_api) | Paginated API consumption | O(n) | REST API, pagination, async |
| [`0x07-rotate_2d_matrix`](0x07-rotate_2d_matrix) | Rotate matrix 90° in-place | O(n²) | In-place matrix manipulation |
| [`0x08-making_change`](0x08-making_change) | Coin change (greedy/DP) | O(n×amount) | Dynamic programming, greedy |
| [`0x09-island_perimeter`](0x09-island_perimeter) | Grid perimeter calculation | O(rows×cols) | Grid traversal, DFS |
| [`0x0A-primegame`](0x0A-primegame) | Prime game (optimal play) | O(n log log n) | Game theory, Sieve of Eratosthenes |
